# 场景 4：参考 PPTX 或图片制作新稿

## 主参考

先分析每份参考的画布、颜色、字体层级、间距、版式语法、图像语言和页面节奏。多份参考冲突时，必须由用户指定主参考；其他参考只能提供明确的次级元素，不得自动平均。

## 策划与版式

依次完成：

```text
brief.json → reference_profile.json → evidence_plan.json → outline.json → slide_plan.json
```

默认可搜索外部信息，但证据必须确认后才能进入正式内容。`slide_plan.json` 必须逐页锁定每个可见文字块的完整文字、`[x,y,w,h]` 大致位置、对齐方式和阅读顺序，并记录资产预留区与装饰安全区。随后生成覆盖全部页面的无风格 `layout-preview.pptx`；文字或位置未确定时不得制作代表页。

## 代表页

参考稿已经定义风格，因此不做三选一。制作封面、普通正文、复杂页面三页生产级代表稿；它们必须直接复用。用户确认后，再按已批准的 `asset_plan.json` 批量生成。

不得声称从图片恢复了原始 Theme/Master/Layout；只能说明提炼并新建了可观察的设计规则。
