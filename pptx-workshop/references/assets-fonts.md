# 证据、资产与字体

## 外部证据

场景 1/4 默认允许搜索。先记录候选来源、支持的主张、时间和可信度；只有 `evidence-inclusion` 确认范围内的条目可标记 `included: true` 并进入页面。

## 资产计划

每个资产记录 ID、页面、用途、类型、来源/生成方式、裁切、可编辑性和审批状态。批量生成前确认完整计划；新增计划外资产时重新确认。

场景 1 的最终页图必须以 `asset_type: png` 登记为覆盖全画布、包含语义文字且不可编辑的资产，并逐页绑定最终 PPTX。场景 3 的图片层由 Gorden 原版决定，父运行登记最终使用的 PNG/SVG、来源、页面和编辑性影响即可；不要求 `reconstruction_method` 或 `source_region`。其他场景允许经确认的 `svg`、`raster` 或原生 PowerPoint 对象。

内置风格库完整保留在 `assets/style-library/`，是可选参考资料，不是默认最终资产。只有用户在 Gorden A1 或其他场景中明确选择后，实际使用的图片、SVG、艺术字才进入运行资产登记。不得把参考稿中的照片、品牌、数据或正文因“已经打包在 Skill 中”而视为默认可用。

## 字体

先审计所有指定或模板字体。缺失字体时停止自动构建并列出：字体名、涉及页面/对象、影响和候选处理。

只有用户确认后才可：

- 选择替代字体；
- 使用 SVG/图片艺术字替代；
- 保留原字体名并接受本机预览差异。

场景 2–5 的普通正文不得自动替换成图片。场景 1 有意把整页成稿封装为图片，所有文字必须在图片生成时校对准确，并明确不可编辑。标题艺术字若转资产，必须披露编辑边界。

标题艺术字使用 SVG 时必须在导出前把全部字形转为轮廓路径；任何 `<text>` 元素都会被 `scripts/validate_svg_assets.py` 拒绝。需要继续编辑文字内容时应保留或另建原生 PowerPoint 文本框，不能把带 `<text>` 的 SVG 当作可交付艺术字资产。
