# Context 维护规则

本参考文件定义长期上下文层的写入边界。项目本地 `AGENTS.md` 优先级高于本文件。

Context 采用双时间线：`context/diary/` 是用户个人跨项目的全局时间线；persona 中的项目文件是各项目的精简时间线。前者忠实保存每天实际做过的事，后者只保存项目阶段变化并指向对应日记。

## 触发与判断

Context 写入只发生在实际对话过程中。不得创建每日自动化任务，也不得因为日期变化自动生成空日记。

- 只要通过实际对话完成了可确认的工作，任务结束时就应追加当日日记。例行摄入、检查、维护和同步也属于工作，可将同一任务的连续步骤合并简记。
- 任务失败、遇到阻塞或形成明确下一步时，记录实际尝试、验证结果和当前边界。
- 只有项目阶段、里程碑、关键决策、阻塞或下一步变化时，才更新对应项目画像。
- 只有跨项目长期有效的个人偏好、身份或工作方式变化时，才更新用户画像。

普通闲聊、纯讨论、未执行设想、没有结果的重复操作和逐句对话不写入 Context。

触发词包括 `更新画像`、`更新日记`、`记录偏好`、`记录项目进展`、`同步上下文`、`context`。用户明确要求时必须写入，但仍须遵守事实与隐私边界；没有触发词不代表可以跳过实际完成工作的日记收尾。

## 可写内容

全局日记记录以下内容：

- 当天实际完成的操作、产物和结果。
- 关键处理、验证方法和验证结果。
- 失败、阻塞、未解决边界和明确下一步。
- 用户明确作出的决定、约束或偏好，以及当前交互中确认的决策倾向。

不得把 Agent 的推断、观察、心理分析、猜测或未确认的长期偏好写成日记内容。不得把计划写成已完成，也不得编造验证结果。日记不包含 `Agent Observations` 一类章节。

## 路由与历史

1. 完整事件首先写入当日日记；如果不存在当日日记才新建。一天可包含多个项目，同一任务的连续推进应合并或追加，避免重复。
2. 若事件改变项目阶段、里程碑、关键决策、阻塞或下一步，将一句到数句的项目级摘要写入对应项目文件。
3. 每条项目时间线记录必须使用相对 Markdown 链接指向对应日记；项目文件不复制日记全文。日记也应链接相关项目画像。
4. 若事件形成跨项目长期有效的个人偏好、身份或工作方式，再更新用户画像。普通完成事项只写日记。
5. Persona 与项目文件采用“当前状态 + 日期化演化记录”，只追加或谨慎修订，不静默删除旧状态。
6. Context 不强制使用 Wiki 的英文 slug wikilink 规则。
7. 每次由 Codex 写入的 Context 内容署名 `Codex Win端`。
8. 一天没有实际完成或可确认进展时，不创建空日记。

## 隐私

Context 中不记录护照号、注册号、密钥、token、联系方式等真实敏感值；不使用部分掩码或占位符替代。只保留必要的事件事实和用户决策。

## Frontmatter 与远程访问

新建或实际触碰的 Context Markdown 使用 UTF-8 无 BOM，并包含：

```yaml
---
type: context-diary | context-persona | context-project | context-guide
date: YYYY-MM-DD
updated: YYYY-MM-DD
remote_access: always | on-demand | local-only
---
```

推荐分层为：`context/DIARY_GUIDE.md`、用户画像和项目画像使用 `remote_access: always`，用于每次查询读取稳定上下文；日记使用 `remote_access: on-demand`，只在需要追溯近期事件、历史过程或决策演化时读取。若项目明确支持 `local-only`，该类文件不得进入远程 Gateway 索引。

## 网页端检索

Gateway 的定时任务只负责已有文件的索引校准和续跑，不生成或修改 Context。推荐每次查询检索 persona/项目画像稳定层；只有涉及近期事件、历史过程、决策演化、日记撰写规则或 Context 维护方式时，才追加 diary 和 `DIARY_GUIDE.md`。Context 只能提供个人化上下文，不能替代外部来源证据。

脱敏日记模板见 [`references/diary-template.md`](diary-template.md)。使用时复制到项目的 `context/diary/YYYY-MM-DD_Diary.md`；如需让网页端 GPT 参考规则和模板，可复制为 `context/DIARY_GUIDE.md`，并保留 `remote_access: always`。Gateway 只索引该已存在的指南，不生成或修改 Context。
