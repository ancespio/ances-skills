# 日记模板

本文件是可复制的脱敏日记模板，不包含任何用户真实信息、私人路径、凭据或具体项目内容。日记是用户个人跨项目的全局时间线，应忠实记录当天实际完成的工作，而不是只记录“重大事件”。

使用时，将模板复制到知识库的 `context/diary/YYYY-MM-DD_Diary.md`；若作为网页端规则与模板入口，可复制为 `context/DIARY_GUIDE.md`，并设置 `remote_access: always`。

## 模板

```markdown
---
type: context-diary
date: YYYY-MM-DD
updated: YYYY-MM-DD
remote_access: on-demand
---

# YYYY-MM-DD

关联： [相关日记](YYYY-MM-DD_Diary.md)；[相关项目画像](../persona/Project_<slug>.md)。

## 今日摘要

- [概括当天已完成的工作和结果；一天可涉及多个项目]

## 今日完成

- [项目/任务名称]：[已完成的操作、产物和结果]
- 验证：[实际执行的检查及结果]

## 问题与处理

- 问题：[用户确认的问题]
- 处理：[已经采取的处理]
- 验证：[用户确认或可观察到的结果]

## 决策与状态变化

- 决策：[用户明确作出的决定]
- 状态变化：[项目或工作状态的已确认变化]

## 涉及项目

- [项目名称](../persona/Project_<slug>.md)：[当天进展的一句话摘要]

## 阻塞与下一步

- 阻塞：[用户确认的阻塞]
- 下一步：[用户确认的下一步]

## 可复用经验

- [从已发生事实中提炼的操作经验，不写未经确认的推断]

Codex Win端
```

## 写入边界

- 只要实际完成了可确认的工作，任务结束时就追加当日日记；例行摄入、检查、维护和同步可以按任务合并简记。
- 记录实际操作、结果、验证、失败/阻塞和明确下一步，以及用户明确作出的决定和当次确认的决策倾向。
- 不写 Agent 推断、观察、心理分析、猜测或未确认的长期特征。
- 不把未执行方案写成已完成，不编造结果或验证，不逐句复述对话。
- 普通闲聊、纯讨论和没有结果的重复操作不写；一天没有实际完成或可确认进展时，不创建空日记。
- 只有项目阶段、里程碑、关键决策、阻塞或下一步变化时才更新项目画像；项目画像写简短摘要并链接本日记，不复制完整过程。
- 不记录真实身份号码、密钥、token、联系方式等敏感值，也不写部分掩码或占位符。
- 跨日期事件使用相对 Markdown 链接；模板中的 `<slug>` 仅是占位符，复制时替换为实际文件名。
