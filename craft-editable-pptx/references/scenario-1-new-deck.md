# 场景 1：根据资料从 0 制作

## 策划

依次写入并校验：

```text
brief.json → outline.json → slide_plan.json
```

默认可以检索外部资料，但先写 `evidence_plan.json`。候选事实、数据、引用和来源经用户批量确认后才能进入 outline 或页面文案。

## 完整版式预览门

根据 `slide_plan.json` 生成覆盖全部页面的 `layout-preview.pptx`。它只表达：

- 页面标题与主要信息块；
- 每个元素的位置、大小、层级和版式语法；
- 图片、图表、表格、SVG 等资产的预留区；
- 页面密度和阅读顺序。

不得在此阶段讨论动效，也不得把风格选择混入版式确认。真实渲染并写 QA 后，等待用户确认。

## 三套风格门

版式确认后制作 A/B/C 三套风格方向。每套都是可直接进入最终稿的 3 页生产级 PPTX：封面、普通正文、复杂页面。可以先生成高质量 SVG 再转换，也可以直接生成 PPTX；普通文字必须转为原生文本框。

用户选定一套后，复用该套 3 页，不重新生成。再确认 `asset_plan.json`，批量完成其余页面。

## 禁止

- 未确认版式就生成完整正式稿；
- 用一次性风格图片冒充代表页；
- 把未确认外部证据或计划外资产加入正式稿；
- 自动选择风格；
- 增加动画、转场、旁白或视频。
